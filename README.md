
# Overclocked - Student Stress Analyzer

A web application that analyzes a student's academic stress level based on attendance, pending assignments, sleep hours, and exam proximity.

## Features
- Attendance tracking
- Assignment load analysis
- Sleep monitoring
- Exam countdown assessment
- Stress level classification:
  - Stable ✅
  - Heating Up ⚠️
  - Critical 🚨
  - Overclocked ☠️

## Technologies Used
- HTML
- CSS
- JavaScript
